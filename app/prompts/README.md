# app/prompts（LLM のプロンプト置き場。SPEC-000b）

- 1ファイル1プロンプト。ファイル名がプロンプト名（英小文字・数字・`_`・`-`。例: `_sample.md` → 名前は `_sample`）
- コードにプロンプト文を埋め込まない。呼び出しは `callLlm(..., { promptName: "名前" })` で、このフォルダから読み込む
- ファイルの先頭に、`---` で囲んだ見出しを書く（必須: `spec`・`purpose`・`version`。任意: `updated`）。その後ろがシステムプロンプトの本文

```
---
spec: SPEC-001
purpose: 相談内容を相手に伝える文へ言い換える
version: 1
updated: 2026-10-09
---
（ここからシステムプロンプトの本文）
```

- 内容を変えたら `version` を上げ、`updated` を更新する（変更履歴は git で追える）。評価結果のファイルには、プロンプト名と版が記録される
- 良い例: SPEC 番号と版があり、どの評価結果がどの版のものか分かる
- 悪い例: プロンプト文がコードの中の文字列に散らばっている
