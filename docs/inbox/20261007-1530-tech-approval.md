## 訂正（2026-10-07、問い合わせ担当）

上の整理の「Pro/Max プランには Agent SDK 用の月次クレジットがある」は誤り。同じ記事の冒頭に「Update June 15: We're pausing the changes to Claude Agent SDK usage described below.」とあり、別枠のクレジットは導入が停止されている。現状、Agent SDK の利用はプランの通常の利用上限から消費される（開発作業の Claude と枠を共有）。追加課金を有効にしなければ、上限で止まるだけで追加費用は出ない点は変わらない。
また Agent SDK の公式概要（code.claude.com/docs/en/agent-sdk/overview）に「事前承認がない限り、第三者の開発者が自社製品で claude.ai ログインやレート制限を提供することは認めない。API キー認証を使うこと」とある。プラン方式は開発者本人の開発・評価に限り、パートナーなど他人が使う段階では API キー方式が必要（Q-H12）。人間への訂正の報告済み。
